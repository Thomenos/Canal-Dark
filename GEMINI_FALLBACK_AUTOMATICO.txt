🔄 SISTEMA DE FALLBACK AUTOMÁTICO - GEMINI
============================================

O código agora tem FALLBACK AUTOMÁTICO de modelos Gemini!

Se um modelo não funcionar (erro 404, quota, etc), o sistema
automaticamente tenta o próximo modelo da lista.

═══════════════════════════════════════════════════════════

🎯 COMO FUNCIONA:

Quando você roda o código, ele tenta os modelos nesta ordem:

1. gemini-1.5-flash-latest  ← Tenta primeiro (mais recente)
2. gemini-1.5-flash         ← Fallback 1
3. gemini-1.5-pro-latest    ← Fallback 2 (mais preciso)
4. gemini-1.5-pro           ← Fallback 3
5. gemini-2.0-flash-exp     ← Fallback 4 (experimental)

O primeiro que funcionar será usado automaticamente!

🐛 RESOLUÇÃO DE PROBLEMAS:

PROBLEMA: Erro "404 models/gemini-xxx is not found"
SOLUÇÃO: O sistema tentará automaticamente outros modelos!
         Se todos falharem, usará prompt genérico.

PROBLEMA: Erro "429 quota exceeded" em todos os modelos
SOLUÇÃO: Você atingiu o limite DIÁRIO de TODOS os modelos.
         Opções:
         1. Espere até amanhã (reset diário às 00:00 UTC)
         2. Pague plano pago (US$ 7 por 1M tokens)
         3. Use outra chave API Gemini

PROBLEMA: "Nenhum modelo Gemini disponível"
SOLUÇÃO: Todos os 5 modelos falharam.
         1. Verifique sua chave API (app.py linha 32)
         2. Verifique conexão internet
         3. Rode: python listar_modelos_gemini.py
         4. Veja se atingiu quota diária

PROBLEMA: Background fica sempre genérico
SOLUÇÃO: Gemini está falhando (provavelmente quota).
         O sistema usa fallback genérico para não quebrar.
         Espere ou pague plano pago.

🎬 FLUXO DO SISTEMA:

1. Código inicia
2. Precisa gerar background/título/descrição
3. Chama criar_modelo_gemini_com_fallback()
4. Sistema tenta modelos em ordem:
   ❌ gemini-1.5-flash-latest → erro 404
   ❌ gemini-1.5-flash → erro 404
   ✅ gemini-1.5-pro-latest → FUNCIONA!
5. Usa gemini-1.5-pro-latest para gerar conteúdo
6. Próxima vez que rodar, tenta a mesma sequência

VANTAGEM: Você não precisa se preocupar com modelos!
O sistema se adapta automaticamente! 🎯

📚 CÓDIGO TÉCNICO:

A função criar_modelo_gemini_com_fallback() (app.py:186-206):

```python
def criar_modelo_gemini_com_fallback():
    """
    Tenta criar um modelo Gemini, tentando múltiplos modelos em ordem.
    Retorna (model, nome_modelo) se sucesso, ou (None, None) se todos falharem.
    """
    genai.configure(api_key=CHAVE_GEMINI)

    for nome_modelo in MODELOS_GEMINI_FALLBACK:
        try:
            model = genai.GenerativeModel(nome_modelo)
            # Testa se o modelo funciona com um prompt simples
            test_response = model.generate_content("Hi")
            if test_response.text:
                print(f"   ✅ Modelo Gemini ativo: {nome_modelo}")
                return model, nome_modelo
        except Exception as e:
            # Se falhar, tenta o próximo
            continue

    # Se todos falharem, retorna None
    return None, None
```

COMO FUNCIONA:
1. Percorre lista de modelos (MODELOS_GEMINI_FALLBACK)
2. Para cada modelo, tenta criar e testar com "Hi"
3. Se funcionar, retorna o modelo
4. Se falhar, silenciosamente tenta o próximo
5. Se todos falharem, retorna None
6. O código que chama essa função usa fallback genérico se None
