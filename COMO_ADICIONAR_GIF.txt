🎬 COMO BAIXAR E ADICIONAR GIF DE INSCRIÇÃO
=============================================

## 📥 PASSO 1: BAIXAR O GIF

### OPÇÃO A: Canva (RECOMENDADO - Personalizável!) ⭐

1. Acesse: https://www.canva.com
2. Crie conta grátis (se não tiver)
3. Busque por: "subscribe button" ou "inscreva-se"
4. Escolha um template animado
5. Personalize:
   - Mude cores
   - Adicione seu nome do canal
   - Ajuste tamanho
6. Baixe como GIF animado

### OPÇÃO B: Sites de GIFs Gratuitos

**Tenor** (https://tenor.com)
- Busque: "subscribe button gif"
- Busque: "subscribe animation"
- Clique no GIF → "Download GIF"

**Giphy** (https://giphy.com)
- Busque: "subscribe button"
- Busque: "youtube subscribe"
- Clique → "Download"

**Pixabay** (https://pixabay.com)
- Busque: "subscribe gif"
- Busque: "button animation"
- Download gratuito

**Freepik** (https://www.freepik.com)
- Busque: "subscribe gif"
- Alguns são gratuitos, outros premium

### OPÇÃO C: Google Imagens

1. Google: "subscribe button gif transparent"
2. Google: "inscreva-se gif animado"
3. Google: "youtube subscribe gif"
4. Clique com botão direito → "Salvar imagem como..."

## 🎨 PERSONALIZAÇÃO DO GIF

No arquivo **app.py**, linha 77-79:

```python
GIF_INSCRICAO = "inscricao.gif"  # Caminho do GIF
ATIVAR_GIF_CTA = True             # True = ativa, False = desativa
```

### Mudar o nome do arquivo:
Se seu GIF tem outro nome:
```python
GIF_INSCRICAO = "meu_gif.gif"
```

### Desativar temporariamente:
```python
ATIVAR_GIF_CTA = False
```

---

## 📍 MUDAR POSIÇÃO DO GIF

No arquivo **app.py**, linha 866 (função criar_video_longo):

```python
video_final = adicionar_gif_overlay(
    video_final,
    GIF_INSCRICAO,
    timestamps_cta,
    duracao_gif=3.0,   # Tempo que fica na tela (segundos)
    posicao="canto"    # MUDE AQUI!
)
```

### Opções de posição:

**"canto"** - Canto superior direito (discreto)
```
┌─────────────────────┐
│              [GIF] │
│                     │
│   SEU VÍDEO        │
└─────────────────────┘
```

**"centro"** - Centro da tela (chamativo)
```
┌─────────────────────┐
│                     │
│      [GIF]         │
│                     │
└─────────────────────┘
```

**"baixo"** - Centro inferior (estilo YouTube)
```
┌─────────────────────┐
│   SEU VÍDEO        │
│                     │
│      [GIF]         │
└─────────────────────┘
```

## 🔧 PALAVRAS QUE ATIVAM O GIF

O código detecta automaticamente quando você diz:

✅ inscreva, inscreve, inscrição, inscrever
✅ like, curtir
✅ compartilhe, compartilhar
✅ sino, notificações

**Exemplos de frases que funcionam:**

"Inscreva-se no canal"
"Deixe seu like"
"Compartilhe este vídeo"
"Ative o sino de notificações"

## 💡 DICAS IMPORTANTES

### Tamanho do GIF:
✅ Recomendado: 300-500px de largura
✅ Formato: .gif ou .mp4
✅ Com fundo transparente fica melhor!

### Duração:
- Padrão: 3 segundos
- Para mudar: altere `duracao_gif=3.0` para o valor desejado

### Quantos CTAs posso ter?
- Quantos quiser!
- O GIF aparece em TODOS os momentos que você pedir para se inscrever

### GIF não aparece?
Verifique:
1. Nome do arquivo está correto? (inscricao.gif)
2. Está na pasta correta? (raiz do projeto)
3. Tem CTA no texto? (palavras: inscreva, like, etc)
4. ATIVAR_GIF_CTA está como True?

## 🔍 RESOLUÇÃO DE PROBLEMAS

### Erro: "GIF não encontrado"
```
⚠️ GIF não encontrado: inscricao.gif
```
**Solução:** Verifique se o arquivo está na pasta correta

### GIF aparece cortado
**Solução:** Use um GIF menor (máx 400px)

### GIF não aparece
**Solução:**
1. Verifique se tem CTA no texto
2. Veja se ATIVAR_GIF_CTA = True
3. Confira se o arquivo existe

### Quer testar sem GIF?
```python
ATIVAR_GIF_CTA = False  # Desativa temporariamente
```
