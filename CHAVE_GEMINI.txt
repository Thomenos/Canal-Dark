💡 DICA PRO:

Crie um arquivo chamado "config_local.py" com suas chaves:
```python
CHAVE_GEMINI = "sua_chave_aqui"
```

Adicione ao .gitignore:
```
config_local.py
```

No app.py:
```python
try:
    from config_local import CHAVE_GEMINI
except:
    CHAVE_GEMINI = "COLE_SUA_CHAVE_AQUI"
```

Assim suas chaves ficam separadas e protegidas! 🔒
